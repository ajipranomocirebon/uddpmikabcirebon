Opsional — boleh dikosongkan/0 kalau tidak ada pengambilan yang gagal pada kegiatan ini.

Total Pengambilan 0

Total Pengambilan = Sub Total Perolehan Pengambilan + Sub Total Gagal Pengambilan.

Epidemiologi (skrining reaktif) merupakan bagian dari Sub Total Perolehan Pengambilan di atas — bukan penjumlahan tambahan — karena skrining reaktif dilakukan terhadap nomor kantong yang secara hasil uji lab dinyatakan reaktif dari data perolehan yang sudah diinput. Boleh dikosongkan kalau tidak ada hasil reaktif pada kegiatan ini. Satu nomor kantong bisa reaktif pada lebih dari satu parameter sekaligus — tambahkan nomor kantongnya dulu, lalu gunakan "+ Tambah Parameter" di dalamnya untuk memilih parameter mana saja yang reaktif (daftar pilihan parameter diatur lewat tab ⚙️ Setting → Input Parameter).

Belum ada nomor kantong reaktif ditambahkan.

Kalau Epidemiologi (skrining reaktif) di atas dikosongkan, Zona otomatis terisi "Aman" dan terkunci. Begitu ada Nomor Kantong ditambahkan, Zona wajib dipilih manual. Daftar zona diatur lewat tab ⚙️ Setting → Input Zona.

Status Penyimpanan

Memeriksa status penyimpanan…

Semua data (Master Data & Kegiatan) tersimpan otomatis di database lokal browser ini (IndexedDB) setiap kali Anda menyimpan sesuatu — tidak perlu koneksi internet, dan tetap berfungsi persis sama walau aplikasi ini sudah di-deploy/host di website apa pun (GitHub Pages, Netlify, cPanel, dsb). Data hanya tersimpan di perangkat/browser ini saja -- kalau Anda buka aplikasi ini dari HP atau komputer lain, datanya belum ikut muncul di sana kecuali dipindahkan manual lewat Export/Import di bawah ini.

⬇️ Unduh Cadangan

Simpan seluruh data (Master Data + Kegiatan) sebagai satu file .json -- untuk backup rutin atau untuk dipindahkan ke perangkat lain.

⬆️ Pulihkan dari Cadangan

Pilih file cadangan .json yang pernah diunduh. Gabung menambahkan data baru tanpa menghapus yang sudah ada; Ganti menimpa total data di perangkat ini dengan isi file.
